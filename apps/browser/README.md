# Private browser application

Actual public core/HTTP source/browser loader composition, native semantic form and
local downloaded-provider validation. Not a server proxy. Co-located view/HTML/styles
use semantic Pylons tokens, labelled controls, live status and keyboard operation.
Original early entry remains in `tests/feasibility/apps/browser` for independent proof.
See [demo runbook](../../docs/demo.md). No publishable browser package or Ghost adoption.

Keep `bun run demo` running and open its printed `/browser` URL. Title `four` is
valid for A (basic-validation, minimum3), invalid for B (minimum8 plus reference-required).
Load the long fixture for valid B, then clear Reference for invalid B. The host's
credential-policy is not a remote third plugin.

Lifecycle cards show only the selected tenant's actual snapshots, including retained
generations without a current-row claim. Expand details for identity/scope/revisions;
missing applied revision says `not applied`. Contribution metadata supplies declared
capability names, not a readiness boolean. Blocked is not always lazy: dependencies
may block execution. Metadata discovery, executable loading and scoped activation
are distinct. Refresh rereads metadata/configuration; restart the demo for fresh60s
grants. Status remains live, but generation-card updates do not spam announcements.
