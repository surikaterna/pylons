Plugins and lifecycle

Metadata describes plugins and declared capabilities without downloading executable code. Validation demands code, then initializes tenant-scoped instances. A state of blocked is not necessarily lazy loading: dependencies can also block execution.

Tenant A: basic-validation, minimum 3 title characters. Tenant B: basic-validation, minimum 8, plus reference-required. The credential-policy capability belongs to the host; it is not a third remote plugin.

Try title “four”: A is valid, B is invalid. Load the long document fixture for a valid B example, then clear its reference to make B invalid. Refresh metadata does not renew authorization; restart the demo for fresh 60-second grants.
