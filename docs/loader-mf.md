## R1 terminal publication remediation

Auditor `01a0f52c-0eb2-7098-a557-203a3b9237d2` found that evaluation could win
the race before last-caller cancellation, while the unsettled shared promise
still cached success. Its exact fresh-process probe was reproduced: first caller
cancelled, owned signal aborted, zero subscriptions, but exact retry succeeded.
The original before-evaluation cancellation tests did not cover this boundary.

Shared settlement now validates abandonment and marks the flight terminal in one
synchronous transition; only its approved terminal result is cached. The execution
race also revalidates cancellation before returning. Native AbortSignal composition
keeps owned work linked through shared settlement even after execution cleanup;
explicit race listeners and deadline timers are released in finally. Reservations
remain terminal, including failed/cancelled flights: no unsafe different-version
retry or weakened README promise. A surviving lease still permits cached success.

`packages/loader-mf/test/publication.test.ts` adds deterministic synchronous-Promise
and async-evaluator completion-boundary regressions and matching surviving-caller
controls. Both abandonment cases failed before the fix. They now require cancelled
caller/terminal exact retry, aborted owned signal, zero retained subscriptions,
one evaluation and denied alternate version. Controls require the same successful
cached factory, non-aborted work and no retained subscriptions. These are private
unit evaluator-seam probes, not replacement evidence for actual HTTP MF execution.
Full root, real-MF 49-case, packed-target and unchanged logger/privacy/shutdown
gates are rerun; superseding hashes/fingerprint are recorded on canonical `.6`.
